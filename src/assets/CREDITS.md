# Photo credits

The full, linked list of every built-in photograph is in
[`PHOTO-SOURCES.md`](../../PHOTO-SOURCES.md) at the repository root.

All built-in photos are real photographs (not AI-generated or AI-upscaled).
Most come from Wikimedia Commons; the Coltan photo is supplied by COOMIAC
PROJET. They are stored locally in this folder and in `site/` so they can be
replaced without touching external URLs.

To swap a photo, either replace the matching `.webp` file here, drop a JPG/PNG
into `photos-to-add/` and run `npm run photos:optimize`, or upload a new photo in
**Admin → Photo gallery**.
